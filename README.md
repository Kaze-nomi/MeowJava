Описание каждого из проектов находится соответственно в README папки проекта.
Для каждого из проектов реализованы покрытия тестов с плагином JaCoCo.

Кратко:

# MeowZoo - система управления логистикой зоопарка с использованием принципов SOLID и паттернов ООП

# MeowBank - управления банковским аккаунтом с использованием принципов SOLID, GRASP, паттернов ООП и использованием БД.

# MeowImprovedZoo - проект с использованием Clean Architecture и DDD.

# MeowAntiplagiat - система антиплагиата на основе микросервисной архитектуры. Связь между микросервисами через gRPC. Для каждого сервиса своя БД.

# MeowShopping - самый большой проект. В основе проекта микросервисная архитектура. Реализована отказоустойчивая запись и чтение БД каждого из сервисов, frontend на React, синхронное взаимодействие через gRPC, асинхронное взаимодействие с frontend'ом через kafka, websocket уведомления, паттерны outbox и inbox...
