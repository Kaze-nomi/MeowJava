Определения:

1. Что позволяет нам ООП:  
   Объектно-ориентированное программирование (ООП) позволяет моделировать реальный мир с помощью объектов, упрощая разработку, поддержку и расширяемость кода. Например, в приложении для магазина можно создать объекты "Товар", "Корзина" и "Покупатель".

2. Реализация:  
   Реализация — это процесс создания конкретного функционала, описанного интерфейсами или абстрактными классами. Например, интерфейс Animal может иметь метод makeSound(), а класс Dog реализует его как bark().

3. Ассоциация:  
   Ассоциация описывает связь между двумя объектами, например, один объект может ссылаться на другой. Пример: объект "Учитель" связан с объектами "Студенты" через список студентов.

4. Композиция:  
   Композиция — это "жёсткая" связь, при которой один объект не может существовать без другого. Пример: объект "Человек" содержит объект "Сердце", и без сердца человек не существует.

5. Агрегация:  
   Агрегация — это "слабая" связь, при которой объект может существовать отдельно от другого. Пример: объект "Университет" агрегирует объекты "Студенты", но студенты могут существовать вне университета.

6. Полиморфизм:  
   Полиморфизм позволяет одному интерфейсу иметь множество реализаций. Например, метод draw() может быть реализован по-разному для классов Circle и Square.

7. Наследование:  
   Наследование позволяет одному классу унаследовать свойства и методы другого класса. Пример: класс Car наследует свойства класса Vehicle, такие как скорость или тип двигателя.

8. Инкапсуляция:  
   Инкапсуляция скрывает детали реализации объекта и предоставляет доступ только к необходимым данным через методы. Например, поле balance в классе BankAccount может быть приватным, а доступ к нему осуществляется через методы getBalance() и deposit().

9. +1 уникальный факт об ООП в Java:  
   Java поддерживает только одиночное наследование классов (один родительский класс), но позволяет множественное наследование через интерфейсы. Это помогает избежать проблем "алмаза" в наследовании.
