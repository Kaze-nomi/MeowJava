Подробные описания всех проектов можно найти в соответствующих файлах README в папках проектов.
Для всех проектов разработаны Unit-тесты. Код покрыт тестами с помощью плагина JaCoCo.

Кратко:

1. **MeowZoo** — система для управления логистикой зоопарка, разработанная с учетом принципов SOLID и паттернов ООП.

2. **MeowBank** — система для управления банковским аккаунтом, созданная с применением принципов SOLID, GRASP и паттернов ООП, а также с использованием базы данных.

3. **MeowImprovedZoo** — проект, разработанный с использованием Clean Architecture и DDD.

4. **MeowAntiplagiat** — система антиплагиата, основанная на микросервисной архитектуре. Микросервисы взаимодействуют через gRPC, каждый сервис имеет свою базу данных.

5. **MeowShopping** — самый масштабный проект. Он использует микросервисную архитектуру, обеспечивая отказоустойчивую запись и чтение данных в базе данных каждого сервиса. Фронтенд разработан на React, взаимодействие с сервисами осуществляется через gRPC (синхронно) и Kafka (асинхронно). Также реализованы websocket уведомления, паттерны outbox и inbox и многое другое...
